# simple-arcade

ساخته‌شده توسط مغز NCP — اجرای #5

## اجرا
1. پوشه‌ی ZIP را خارج کنید.
2. فایل **index.html** را با مرورگر باز کنید (دوبار کلیک).

نیازی به نصب، سرور یا مرحله‌ی build نیست.

## فایل‌ها
- `index.html` — نقش‌آرای اصلی بازی شامل عنوان، ناحیهٔ رندر (canvas)، نوار امتیاز، دکمهٔ شروع/خاتمه و اتصال به فایل‌های script و style
- `style.css` — استایل‌بندی کلی صفحه، چیدمان عناصر، استایل دکمه‌ها، فرمت‌بندی نوار امتیاز و تم رنگی باکس بازی
- `main.js` — طرح منطقی بازی: تعریف کلاس بازیکن/اشیا، چرخهٔ رندر با requestAnimationFrame، کنترل‌های ورودی، تشخیص برخورد، محاسبهٔ امتیاز و منطق بازگشت به حالت اولیه

## وضعیت اعتبارسنجی
✓ همه‌ی فایل‌ها بررسی شده‌اند و خطای نحوی یا ارجاع شکسته ندارند.
