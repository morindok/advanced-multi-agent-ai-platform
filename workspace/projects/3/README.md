# mushroom-runner

ساخته‌شده توسط مغز NCP — اجرای #3

## اجرا
1. پوشه‌ی ZIP را خارج کنید.
2. فایل **index.html** را با مرورگر باز کنید (دوبار کلیک).

نیازی به نصب، سرور یا مرحله‌ی build نیست.

## فایل‌ها
- `index.html` — ساختار اصلی صفحه شامل کانتینر بازی، رابط کاربری (HUD) برای نمایش امتیاز و جان، منوی شروع و پایان بازی، و بارگذاری ماژول‌های JavaScript
- `style.css` — استایل‌دهی بصری به بازی، تنظیمات کانتینر، استایل UI، انیمیشن‌های ساده و اطمینان از ریسپانسیو بودن بازی در مرورگر
- `js/config.js` — تعریف ثابت‌های بازی شامل ابعاد صفحه، سرعت بازی، تنظیمات فیزیک (گرانش، ضربه)، و تعریف مراحل (Level Data) شامل چیدمان زمین، دشمنان، و موانع برای مرحله اول تا آخر
- `js/entities.js` — تعریف کلاس‌های اصلی بازی شامل بازیکن (با حالت‌های حرکت، پرش، حمله)، دشمنان (قارچ‌های متحرک)، پلتفرم‌ها، و گیت‌های مرحله (Flag)
- `js/input.js` — مدیریت ورودی‌های کاربر (کلیدهای جهت، پرش، حمله) با پشتیبانی از کیبورد و رویدادهای لمس برای موبایل
- `js/gameLoop.js` — لープ اصلی بازی شامل مدیریت زمان (Delta Time)، فراخوانی منطقات به‌روزرسانی فیزیک، تشخیص برخورد، و رندر در هر فریم با استفاده از requestAnimationFrame
- `js/renderer.js` — منطق رندرینگ بازی روی Canvas، مدیریت دوربین (Camera) برای اسکرول خودکار، و رسم تمام موجودات و محیط
- `js/levels.js` — مدیریت وضعیت مراحل، بارگذاری داده‌های مرحله فعلی از config، و منطق عبور از مرحله و پیشرفت به مرحله بعدی تا مرحله پایانی

## وضعیت اعتبارسنجی
- ⚠ js/config.js: خطای نحوی JavaScript: Unexpected end of input
- ⚠ js/renderer.js: خطای نحوی JavaScript: Unexpected end of input
