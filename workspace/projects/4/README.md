# snake-game

ساخته‌شده توسط مغز NCP — اجرای #4

## اجرا
1. پوشه‌ی ZIP را خارج کنید.
2. فایل **index.html** را با مرورگر باز کنید (دوبار کلیک).

نیازی به نصب، سرور یا مرحله‌ی build نیست.

## فایل‌ها
- `index.html` — ساختار HTML اصلی: تگ <canvas> با ID='gameCanvas'، تگ <title> برای عنوان بازی، بارگذاری فایل‌های style.css، input.js و game.js به ترتیب
- `style.css` — استایل کامل بازی: پس‌زمینه تیره، وسط‌چین کردن canvas با نمایش مختصات و امتیاز بالای صفحه، فونت مناسب، حاشیه و سایه دور canvas، استایل دکمه شروع مجدد
- `game.js` — منطق اصلی بازی مار: آرایه بدن مار، حرکت خودکار در گرید، تولید غذا در موقعیت تصادفی غیر از بدن مار، تشخیص برخورد با دیوار و خود، افزایش طول مار با خوردن غذا، محاسبه امتیاز، کنترل سرعت با setInterval، تشخیص state پایان بازی و نمایش امتیاز نهایی
- `input.js` — مدیریت ورودی کیبورد: گوش‌دادن به رویداد keydown، تغییر جهت مار با کلیدهای جهت‌دار، جلوگیری از برگشت معکوس (مثلاً وقتی مار به راست می‌رود نمی‌تواند ناگهان به چپ برود)، دکمه space برای شروع مجدد بازی هنگام باخت

## وضعیت اعتبارسنجی
✓ همه‌ی فایل‌ها بررسی شده‌اند و خطای نحوی یا ارجاع شکسته ندارند.
